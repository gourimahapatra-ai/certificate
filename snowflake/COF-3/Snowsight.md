# Snowsight Homepage — Summary

The Snowsight homepage is the **starting point** of Snowflake’s modern web interface. It provides quick access to key tools, recent activity, and navigation elements that help users work efficiently with Snowflake.  


---

## 🔹 Main Sections of the Snowsight Homepage

### **1. Navigation Menu**
Located on the left side, this menu provides access to major Snowflake features, including:
- Worksheets  
- Databases, schemas, and objects  
- Data products and Snowflake Marketplace  
- Notebooks, Streamlit apps, dashboards  
- Admin functions (users, roles, integrations)  


---

### **2. Search Bar**
A global search tool that helps you quickly find:
- Tables, views, schemas  
- Functions and procedures  
- Worksheets, dashboards, notebooks  
- Data products  


---

### **3. Quick Actions**
Provides shortcuts for common tasks based on your current role, such as:
- Creating a worksheet  
- Uploading files into tables  
- Running Python code  
- Starting a new notebook or project  


---

### **4. Recently Viewed**
Displays tabs showing your most recently accessed items:
- Worksheets  
- Projects  
- Notebooks  
- Streamlit apps  
- Dashboards  
This helps you quickly resume work.  


---

## 🔹 Additional Notes
- The homepage appears automatically when Snowsight is opened.  
- Some features may not be available in all Snowflake regions or platforms.  


---

## 📘 Summary
> The Snowsight homepage provides navigation, search, quick actions, and recent activity panels, giving users a centralized and efficient starting point for working with Snowflake.
